Aviso de Execução Web

Você abriu o index.html diretamente pelo arquivo local!

Os navegadores (Chrome, Edge, etc.) não conseguem rodar aplicações modernas em React e TypeScript dando dois cliques no arquivo, pois eles bloqueiam módulos de script locais por segurança (CORS) e precisam de um servidor web (Vite/Node.js) para compilar o código.

👉 Como ver esta aplicação funcionando:

  1. Online no navegador: Acesse pelo link fornecido no AI Studio.
  2. No seu computador: Abra o terminal nesta pasta e execute npm install e depois npm run dev.

💡 Lembrete: A sua calculadora em Python não precisa de navegador! Para testá-la, abra o terminal e digite: python calculadora.py.
